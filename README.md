## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们从数据源捕获变更事件后要按序交给下游消费，下游偶尔会慢，事件也不能乱序。请从零实现一个变更事件缓冲组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 事件带全局序号，按序号顺序产出，不得跳号；2) 支持按聚合键分区：同一聚合键的事件严格有序，不同聚合键可并行消费；3) 下游处理失败时支持重试，重试失败进入隔离区（死信），但不得阻塞该聚合键之后的事件以外的其它分区；4) 支持位点提交：消费方确认某序号后，之前的缓冲可被清理；5) 支持重放：从指定位点重新产出事件，重放不得影响正在进行的消费位点；6) 提供统计：写入数、产出数、隔离数、当前积压量与最老未确认序号；7) 测试覆盖顺序保证、分区并行、失败隔离、位点提交后清理与重放隔离性；`mvn -q verify` 一条命令跑通。
